


List Module with Bottom up merge sort 


AIA currently has a reasonable animation of top down merge sort for
arrays. This is a recursive algorithm.

The clients would like this team to implement animation of bottom up
merge sort, an algorithm that is iterative but uses the identical
merge operation, so there is substantial common code.



If this is completed successfully, the team could move on to other
similar algorithms, such as natural merge sort (a variant of
bottom up merge sort), and top down merge sort for lists (where lists
are represented using arrays; this may be used by another team that is
implementing animation of lists represented using pointers).
